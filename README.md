# FreeChess ♟️

A responsive, installable chess experience with a Stockfish-powered chess engine and four richly styled dark Liquid Glass color themes.

## Features
- Stockfish 19 Lite powers the opponent in a dedicated Web Worker, with adjustable strength presets from **100 to 3000 Elo** in 100-point increments.
- Four color-only themes: **Red**, **Green**, **Blue**, and **Yellow**, each with a distinct accent palette and matching board colors.
- Dedicated play page at `/play`, legal moves, move history, undo, board flip, and game-state detection.
- Chess runs locally in the browser; no account or game-data upload.
- PWA manifest, service worker, and Apple Home Screen metadata.

## Run locally
```bash
npm install
npm run dev
npm run build
```

## Strength note
The Elo selector is an approximate strength target, not a certified rating. Stockfish skill settings are used for beginner levels and its Elo-limiting option for stronger levels; actual playing strength varies with device performance and thinking time. The browser loads the single-threaded Lite engine (about 1.7 MB plus its WASM file) in a Web Worker so the board remains responsive. Stockfish is GPL-3.0; its license is copied into the deployed engine folder.

## Install
On iPhone/iPad, open the site in Safari, tap Share, then **Add to Home Screen**. On desktop/Android, use the browser's install option when available.


## Expanded game features
- `/import` — load a PGN game or FEN position and continue from that exact position.
- `/online` — create a private room and play another human with real-time move sync.
- `/learn` — a progressive fundamentals-to-strategy curriculum with checkpoints and saved lesson completion.
- `/analysis` — review PGN moves against Stockfish for best-move comparisons and evaluation swings.
- `/login` and `/signup` — email/password, Google OAuth, and Apple OAuth through Supabase Auth.
- Learning progress is stored locally for guests and synced to the signed-in user's account when the backend is configured.

## Enable accounts, cloud progress, and online rooms
1. Create a Supabase project.
2. In **Project Settings → API**, copy the project URL and the publishable/anon key.
3. In Vercel, add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` for Production, Preview, and Development, then redeploy.
4. Run `supabase/schema.sql` in the Supabase SQL Editor. Row-level security ensures users can only read/write their own progress.
5. In Supabase **Authentication → Providers**, enable Email, Google, and Apple. Configure the provider credentials and callback URLs in Supabase and in the Google/Apple developer consoles. Apple OAuth requires Apple Developer credentials; those cannot be generated by the repository.
6. In Supabase **Authentication → URL Configuration**, set the production site URL to the FreeChess Vercel domain and add the deployed preview URLs you use to the redirect allow-list.
7. Enable Realtime for the project. Online rooms use ephemeral Supabase Realtime channels; they do not persist room history in the database.

The repository intentionally contains no provider secrets. OAuth and cloud sync cannot become active until the project's keys and provider settings are supplied in Vercel/Supabase.
